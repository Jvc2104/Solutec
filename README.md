Solutec – Site Web Officiel

Solutec est un site web moderne et responsive développé pour une entreprise spécialisée dans la vente, l'installation et la maintenance de solutions photovoltaïques. Le projet met en avant les services de l'entreprise, ses réalisations et facilite la prise de contact avec les clients.

Le site a été conçu avec une interface épurée, une navigation intuitive et une expérience utilisateur fluide sur ordinateur, tablette et smartphone.

✨ Fonctionnalités
Page d'accueil moderne avec présentation de l'entreprise
Présentation complète des services
Galerie des réalisations
Section FAQ interactive
Formulaire de contact
Design responsive (Desktop, Tablette et Mobile)
Animations CSS et JavaScript
Bouton "Retour en haut"
Navigation fluide
Interface optimisée pour une excellente expérience utilisateur
